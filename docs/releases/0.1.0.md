# PaperMode 0.1.0 Preview 1 — Apple Silicon · Unnotarized

Status: draft prerelease for early testing; downloaded-app acceptance is pending. Apple Silicon only. Tested on the development Mac running macOS 27.2.1; older macOS and Intel are unverified. Current artifacts are ad-hoc signed and not notarized.

- Lock keyboard and pointer input while continuing to watch a course and write paper notes.
- Start from the menu or Control + Option + Command + P, with a visible five-second countdown.
- Unlock by holding Control + Option + Command + L for two seconds, with visible progress.
- Experimental targeted play/pause with Control + Option + Command + Space for supported YouTube and TPStreams players in Chrome and Safari.
- Accessibility permission guidance and session cleanup on sleep or helper failure.

Normal sessions have no automatic timeout. Playback depends on supported English Accessibility controls; changed or ambiguous players are refused. Unlock and use the player normally when playback control is unavailable.

MIT licensed. See the bundled installation instructions and third-party notices. Download the unnotarized-preview ZIP from Assets, extract it, and move PaperMode.app to Applications. Attempt to open it, then use System Settings → Privacy & Security → Open Anyway if macOS blocks it and you trust this official download. Enable PaperMode in Accessibility, close Help and wait for Ready. See the attached INSTALL.md for full instructions. Do not disable Gatekeeper globally.

Known QA limits: external devices, older macOS/Intel, Chrome long-pause, changed/ambiguous targets, hung-browser behavior and final-candidate physical recovery/permission-revocation checks remain unverified in this release round. Local Chrome/Safari full-screen and Safari three-minute pause/resume passed on the earlier recorded candidate; no clean-machine acceptance is claimed.
